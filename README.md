# ToDo App
Aplicación básica de tareas creada con HTML, CSS y JavaScript.

## Funcionalidades
- Añadir tareas
- Marcar tareas como completadas
- Eliminar tareas
- Eliminar todas las tareas completadas
- Guardar tareas en localStorage
- Recuperar las tareas al recargar la página
- Contador de tareas totales, pendientes y completadas

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- LocalStorage

## Objetivo del proyecto
Proyecto realizado para practicar y aprender la manipulación del DOM, eventos, arrays, objetos, funciones, filter(), forEach() y almacenamiento en el navegador.
